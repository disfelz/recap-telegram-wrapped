# Политика конфиденциальности RECAP

## 1. Честное описание прав доступа MTProto
Для подсчёта реальных сообщений за год RECAP использует временную сессию Telegram MTProto.
**Важно:** протокол Telegram MTProto не поддерживает режим «только чтение» — технически выданная сессия обладает широкими правами доступа к аккаунту.

Чтобы минимизировать риски:
- Подключение происходит только после явного согласия пользователя.
- Временный ключ сессии шифруется алгоритмом AES-256-GCM с привязкой к ID пользователя и никогда не попадает в логи или базу данных D1.
- Сразу после завершения анализа, при ошибке или при нажатии «Отменить» сервис вызывает `auth.logOut`, полностью завершая сессию на серверах Telegram.

## 2. Какие данные НЕ сохраняются
- Тексты твоих и чужих сообщений.
- Фотографии, видео, голосовые сообщения, кружки и документы (медиафайлы вообще не скачиваются — читаются только метаданные типа и длительности).
- Одноразовые коды подтверждения, пароли двухфакторной аутентификации (2FA) и открытые session strings.

## 3. Какие данные хранятся
В Cloudflare D1 (строго изолированно по `telegram_user_id`) сохраняются только числовые агрегаты:
- количество отправленных тобой сообщений по месяцам, дням недели, часам и типам медиа;
- длина активных серий;
- рейтинг самых активных чатов (по умолчанию имена собеседников и личные ID скрыты на экспортируемой карточке).

## 4. Передача третьим сторонам
Данные не передаются рекламным сетям, брокерам данных, аналитическим трекерам и моделям ИИ.

## 5. Удаление данных
Ты можешь в любой момент удалить все результаты и отозвать временную сессию:
- через кнопку «Удалить все данные» в настройках Mini App;
- командой `/delete` в Telegram-боте.
