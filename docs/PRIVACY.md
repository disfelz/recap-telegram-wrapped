# Политика конфиденциальности RECAP v2

## Доступ Telegram
RECAP анализирует только исходящие сообщения пользователя за выбранный год. Telegram MTProto НЕ имеет режима «только чтение»: открытая сессия технически обладает широкими правами аккаунта. Вход происходит после явного согласия. Используется отдельная MTProto-сессия сервиса.

После успешной авторизации StringSession шифруется AES-256-GCM с уникальным nonce и AAD, привязанным к telegram_user_id. На диске scanner хранится только зашифрованный сеанс, а ключ — в секретах окружения. В Cloudflare D1 сессия НЕ хранится. По завершении анализа мы вызываем client.disconnect(), а не LogOut, чтобы следующий анализ не требовал нового кода Telegram.

## Какие данные сохраняются
Cloudflare D1: собственные исходящие счётчики по месяцам, неделям, часам, медиа-типам, дни активности, псевдонимизированные рейтинги чатов, технический прогресс и настройки.

В чекпоинтах scanner: Telegram ID диалогов, курсоры сообщений, агрегированные счётчики для восстановления после сбоя; заголовки чатов обезличены. Тексты сообщений и вложения не сохраняются, медиа не скачиваются, коды и пароли 2FA не записываются в базу.

Запрос Telegram WebApp.requestContact отправляет контакт в чат бота: собственный номер ненадолго сохраняется в D1 для передачи Mini App, перестаёт выдаваться через 2 минуты и удаляется после получения либо при периодической автоматической очистке (каждые 15 минут). Экспорт PNG происходит локально без имён и Telegram ID.

## Как отключить и удалить
В настройках Mini App есть кнопка «Отключить аккаунт и удалить все данные». Аналогичное действие — команда /delete в личном чате бота. Анализ останавливается, выполняется Telegram LogOutRequest, удаляются сохранённая сессия, чекпоинты, статистика и настройки. Если Telegram LogOut не подтвердился, API возвращает ошибку, а не ложное сообщение об удалении.

Данные RECAP не включают и не удаляют содержимое сообщений Telegram. Авторизации проверяются в Telegram → Настройки → Устройства.

В RECAP нет платной разблокировки, обязательных подписок на каналы или выдуманных цифр.
