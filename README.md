# RECAP — Telegram Wrapped

**«Твой год. Твои сообщения. Твоя история».**

Полноценный Telegram-бот и Mini App персональной статистики Telegram за выбранный календарный год на основе реальных исходящих сообщений пользователя.

## Ключевые принципы
- Реальная статистика собственных сообщений пользователя (без чужих сообщений и без приблизительных счётчиков `inexact`).
- Никаких обязательных подписок на каналы, репостов и платных разблокировок.
- Защита персональных данных: тексты переписок не сохраняются, медиафайлы не скачиваются, временные MTProto-сессии шифруются AES-256-GCM и завершаются через `auth.logOut`.
- Полностью русскоязычный интерфейс в стиле **Dark Digital Editorial / Futuristic Minimalism**.
- Полная поддержка развёртывания с Android-смартфона/планшета через GitHub Actions + Cloudflare + Render/Railway.

## Структура проекта
- `/frontend` — Telegram Mini App (React + TypeScript + Vite + Motion + Canvas PNG Export).
- `/backend` — Cloudflare Workers API, Cloudflare D1 и обработчики команд Telegram-бота.
- `/scanner` — Python MTProto-анализатор на Telethon + FastAPI (контейнер для VPS / Render / Railway / Fly.io).
- `/shared` — единые TypeScript-типы и контракты данных.
- `/tests` — 12 автоматических тестов алгоритма анализа, пагинации, чекпоинтов и `FloodWait`.
- `/docs` — политика конфиденциальности, архитектура и пошаговая инструкция деплоя с Android.
- `CHATGPT_INSTRUCTIONS.md` — подробная инструкция-контекст для продолжения разработки, аудита и деплоя в ChatGPT.
